# bm25

The script calculates BM25 scores for a small document collection using the parameters:
k1 = 1.6
b = 0.75
The program:
Creates an example input dataset of 6 documents and 10 terms
Computes BM25 IDF and per-term contribution
Calculates an overall BM25 score per document
Displays the input table, the BM25 results table, and a ranking table
